# Bradford-licensed benchmark reference files

These six files are content-preserving copies from the sibling research
workspace:

`TSEMO-Constrain/Test_functions/{ttbuk1,ttbukg1,ttbuk2,ttbukg2,weldbeam,weldbeamconstr}.m`

They are the source evidence for the vectorized SRN, BNH, and welded-beam
definitions in `../../getBenchmarkProblem.m`. The accompanying `LICENSE` is
the BSD 2-Clause license from the root of that Bradford-derived workspace.

The shipped registry is self-contained and does not call these files during
optimization. They are redistributed to preserve formula and license
provenance.
